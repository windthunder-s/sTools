# 截图功能对照与修正依据（2026-10-15）

本轮先审查交互和功能，再改代码，不以工具栏相似或按钮可点击作为完成标准。

## 参考依据

- [Snipaste 官方基础操作](https://github.com/Snipaste/feedback/wiki/Getting-Started)：默认 F1 直接截图；说明当前形状编辑、颜色和笔宽调整、复制保存及贴图。
- [Snipaste 官方快捷键](https://github.com/Snipaste/feedback/wiki/Key-Bindings)：Ctrl+A 全屏、Ctrl+T 贴图、Enter 复制、Ctrl+Y 重做等。
- QQ 官网本轮无法通过检索工具访问，未把第三方教程当成已核实的 QQ 规范。录屏与长截图流程以用户明确提出的需求设计，并对 sTools 自己的实现做实测。

F1 默认直接截图可以少一次选择；选区上方再切换其它模式，保留区域。默认功能由用户明确设置，不因上一次偶尔录屏就改变下一次 F1 的行为。

## 基线实际问题

| 功能                 | 原实现问题                        | 本轮处理                                         |
| -------------------- | --------------------------------- | ------------------------------------------------ |
| 画笔、荧光笔、橡皮擦 | 闭环回到起点整笔消失，单击不绘制  | 按轨迹判断，支持闭环和点                         |
| 颜色、笔宽与文字     | 当前标注完成后不能继续调色/调粗细 | 保留当前编辑状态，完整撤销/重做                  |
| 小尺寸贴图           | 保存、关闭按钮超出窗口            | 控制条自适应布局                                 |
| 录屏倒计时           | 取消后开始按钮永久禁用            | 未编码取消与已录结束分离，可重试                 |
| 媒体请求             | 取消后迟到的流可能未释放          | 每次尝试独立资源，迟到流立即结束                 |
| 重复快捷键           | 录屏准备窗口未算活跃任务          | 准备/选区/录制/滚动均保持单任务                  |
| 模式选择             | 打开后固定，不能保留选区切换      | 主进程校验转换，统一四模式                       |
| 长截图               | 没有采集和拼接实现                | 真实区域采集、稳定验证、垂直重叠匹配、原像素输出 |
| 快速入口             | 没有默认 F1，默认模式不可选       | 中央快捷键注册、冲突可见、已有配置保留           |

六色色板、自定义颜色与三档线宽的基线像素测试已通过；没有将它们误报为全部失效。基线 Enter 用例的失败来自窗口在 keyup 前关闭，已修正测试输入方式，并继续验证真实复制和关闭结果。

复核还修复了连续完成长图的竞态、候选 PNG 编码超过限制后无法导出的问题，以及切换窗口期间取消后又出现新窗口的问题；均增加针对性的源码回归。

## 验证与当前边界

测试检查实际 RGB、实际笔宽、PNG 位图、长图每段原生像素和媒体资源状态。单纯“画面变化”不足以证明颜色正确；输出文件存在也不足以证明长截图没有重复或缺行。

长图仅在稳定且唯一的重叠匹配通过时追加，要求至少 40% 重叠。合成测试包含固定栏、动画单像素、重复纹理、上滚、无重叠和 1920 × 1080 图像；真实 Electron 测试另外逐段比对输出原生位图。

本机实测单显示器 2560 × 1440、125% 缩放。没有把单机结果称作所有显示器、所有音频硬件或所有应用验证；自动化快捷键用例调用真实注册回调，不等同于物理键盘硬件测试。具体通过数量及日志以 `TESTING.md` 为准。
