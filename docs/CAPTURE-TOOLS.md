# sTools 截图与录屏

0.6.0 内置 `capture-tools`。在主搜索输入「截图与录屏」打开功能面板；「插件快捷键 → 截图与录屏」可统一管理各功能的快捷键。

## 一个常用入口

「快速截图」默认直接进入截图，不弹出前置选择菜单。框选前后都能切换上方的「截图 / 录屏 / 长截图 / GIF」，保留已框区域；切回截图也保留已有标注。再次触发快捷键只聚焦现有任务，不轮换模式、不重复打开准备窗口。

首次升级或安装时，若没有任何已有截图插件绑定，会通过统一快捷键管理尝试 F1。已有绑定一律保留；F1 被其它软件占用会显示提示，不覆盖已有绑定。用户移除后不会在下次启动自动恢复。需要修改或启用时，在插件面板点「设置快捷键」。

插件面板的「快速入口默认打开」可明确改为录屏、长截图或 GIF；只影响快速入口。单独的「区域截图」「区域录屏」等命令始终打开其指定功能，不记忆上一次临时切换的模式。

## 截图与标注

- 框选、移动、八点缩放；矩形、圆形、箭头、画笔、荧光笔、马赛克、文字、橡皮擦。
- 当前标注可继续改颜色、粗细；文字完成输入后仍可改颜色与字号。右键或切换工具提交当前标注；撤销再重做可恢复其编辑状态。暂不支持任意历史对象直接点选、旋转或拖动编辑。
- 预设六色、自定义颜色及当前颜色选中状态；荧光笔半透明，橡皮擦只影响标注图层，不破坏原图。画笔、荧光笔和橡皮擦支持闭环及单击画点。
- 粗细使用整数像素值，默认 4 px、最小 1 px。在画布或粗细控件上滚轮向上加粗、向下变细，每次 1 px，也可直接输入数值；控件同步显示笔尖预览，当前标注的粗细修改支持撤销/重做。
- Enter / Ctrl+C 复制、Ctrl+S 保存 PNG、Ctrl+T 贴图、Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做；Ctrl+A 全屏。选区模式双击复制，方向键移动选区。
- 文字输入时 Enter 完成、Shift+Enter 换行、Esc 放弃当前文字；中文输入法组字期间不拦截 Enter/Esc。右键退出当前标注工具，再右键取消截图。

浅色工具栏靠选区右侧对齐，空间不足自动翻转。颜色/粗细在独立面板中，不挤占主工具行。贴图支持移动、调整窗口大小、透明度、复制、保存；小图也可访问所有控制按钮。

## 录屏与 GIF

框选后确认，准备页可选择系统声音与麦克风。开始前有 3 秒倒计时；准备和倒计时期间可取消并在同一选区重试。实际录制支持暂停/继续、停止预览与保存；录制中关闭先停止生成文件，再次关闭才退出。

视频优先 MP4，编码不可用时 WebM；最高 1920 × 1080 / 30 fps，最长 30 分钟或 512 MB。GIF 固定无声，最长 30 秒，最大边 720 px、目标 10 fps。录屏控制窗从捕获中排除，未另存草稿位于 `.stools/captures/drafts`。

音频权限仅授予明确勾选的会话；摄像头访问拒绝。测试覆盖真实无声录制、权限状态、取消清理和迟到媒体，不代表所有麦克风/系统音频硬件组合均已实测。

## 长截图

1. 框选可滚动正文，避开固定顶部/底部栏、悬浮按钮、滚动条和动画。
2. 切换「长截图」，点「开始长截图」，等待显示就绪。
3. 在原应用内手动向下滚动，每次不超过选区高度的一半，等画面停稳再继续。
4. 点「完成长截图」，检查预览，再复制、保存 PNG 或贴图。取消保存对话框不会丢掉结果。

只拼接验证有足够重叠的稳定画面；停留不追加，上滚不追加。内容变化、滚动过大、重复纹理无法定位、固定栏或动画干扰时明确提示，保留已拼接部分，不盲目接图。当前支持同一选区的垂直手动滚动，未实现自动滚轮驱动、横向拼接或固定栏自动裁切。

输出保留真实像素，最大边 16384 px、总计不超过 4000 万像素，PNG 编码超出输出上限前停止追加，保留上一份可导出的结果。长图在专用预览中复制/保存/贴图，暂不支持在长图上继续标注。缩放或窗口内容布局变化后应重新框选。

## 实现与验证

使用 Electron 桌面捕获、Canvas 标注、MediaRecorder；GIF 使用 MIT 许可的 gifenc 1.0.3。无须安装 Snipaste、QQ 或 FFmpeg。外部 Snipaste 接入继续保留。

只选择鼠标所在显示器或面板指定显示器，不跨屏拼接。当前没有窗口自动吸附、取色放大镜、OCR、截图历史、视频剪辑或摄像头画中画。

测试从源码启动隔离 Electron，以自建屏幕夹具验证真实输出；不修改真实用户配置或剪贴板。基线问题、修复与实际通过记录见根目录 `TESTING.md`；默认快捷键和图像匹配的单元测试分别位于 `tests/main/captureQuickShortcut.test.ts`、`tests/renderer/captureQuickEntry.test.ts`、`tests/capture/vertical-stitch.test.mjs`。
